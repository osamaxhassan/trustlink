==============================================================================
TRUSTLINK — SYSTEM & ENVIRONMENT REQUIREMENTS SPECIFICATION
==============================================================================

1. RUNTIME & SYSTEM PREREQUISITES
------------------------------------------------------------------------------
- Operating System : Ubuntu 20.04+ / Debian 11+ / CentOS 8+ / Windows Server
- Node.js Runtime  : Node.js v20.x LTS or v22.x LTS (Recommended: >= 20.12.0)
- Package Manager  : npm v10.x or higher
- Process Manager  : PM2 (recommended for production: `npm install -g pm2`)
- WebSocket Support: Reverse proxy (Nginx/Apache) MUST have WebSocket / Upgrade 
                     headers enabled for Socket.io.

2. DATABASE SPECIFICATION
------------------------------------------------------------------------------
- Engine           : MySQL 8.0+ OR MariaDB 10.3+
- Storage Engine   : InnoDB (Default)
- Extensions Req.  : Spatial Extensions enabled (ST_Distance_Sphere, POINT)
- Collation        : utf8mb4_unicode_ci
- Database Name    : trustlink_db (or custom specified in .env)
- Initialization   : Import schema from 'trustlink_db.sql'

3. NETWORK & PORT BINDINGS
------------------------------------------------------------------------------
- Internal Port    : 5000 (Configurable via PORT environment variable)
- Protocols        : HTTP/1.1, WebSocket (WSS / WS)
- Public Exposure  : Reverse-proxied via Nginx/Apache on port 80/443 (SSL)

4. REQUIRED ENVIRONMENT VARIABLES (.env)
------------------------------------------------------------------------------
PORT=5000
NODE_ENV=production
DB_HOST=localhost
DB_PORT=3306
DB_USER=your_db_username
DB_PASSWORD=your_db_password
DB_NAME=trustlink_db
DB_SSL=false
JWT_SECRET=generate_a_random_32_character_string_here

5. BACKEND DEPENDENCIES (Managed via package.json)
------------------------------------------------------------------------------
- express          : ^4.19.2 (or ^5.x)
- socket.io        : ^4.7.5
- mysql2           : ^3.9.7 (Promise-based MySQL client)
- bcryptjs         : ^2.4.3 (Password cryptographic hashing)
- jsonwebtoken     : ^9.0.2 (Stateless JWT authentication)
- multer           : ^1.4.5-lts.1 (Multipart form-data & file uploads)
- node-cron        : ^3.0.3 (Background radius expander & purge daemons)
- dotenv           : ^16.4.5
- cors             : ^2.8.5

6. FRONTEND DEPENDENCIES (Built to static files)
------------------------------------------------------------------------------
- react            : ^18.x
- react-dom        : ^18.x
- vite             : ^5.x
- leaflet          : ^1.9.4
- react-leaflet    : ^4.2.1
- socket.io-client : ^4.7.5
- axios            : ^1.6.8
- lucide-react     : ^0.378.0
- tailwindcss      : ^3.4.x

7. APPLICATION DEPLOYMENT COMMANDS
------------------------------------------------------------------------------
1. Build Frontend Static Assets:
   cd trustlink/client
   npm install
   npm run build
   cd ..

2. Install Backend Dependencies:
   cd trustlink
   npm install --production

3. Import Database:
   mysql -u [user] -p [database_name] < trustlink_db.sql

4. Start Production Server:
   pm2 start src/server.js --name "trustlink"
   (OR: node src/server.js)
